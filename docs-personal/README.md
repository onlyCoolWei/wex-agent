# 个人知识库

本目录属于用户个人学习和研究资料，不是 Wex Agent 的产品文档。

除非用户明确要求，否则 Coding Agent 不应读取、总结、修改、格式化或引用这里的内容，也不应把个人笔记中的观点当作业务需求、架构决策或验收标准。`diary.md` 是仓库规则要求维护的唯一例外。

当用户确认某条笔记需要成为项目正式知识时，应人工提炼并移动到：

- `../docs/business/`：产品事实和业务规则；
- `../docs/technical/`：架构、技术方案和实施决策；
- `../docs/design/`：页面流程和交互规范。

当前个人笔记：

- [`study.md`](study.md)：Coding Agent 开源项目研究与学习路线。
- [`vibe-coding.md`](vibe-coding.md)：Vibe Coding 仓库治理方法论。
- [`document-system-proposal.md`](document-system-proposal.md)：业务、设计、技术三类文档体系讨论草案。
- [`codex-document-format.md`](codex-document-format.md)：Codex 优先的业务、设计和技术模块文档格式与模板。
- [`diary.md`](diary.md)：仓库变更结果记录，由 Codex 按根目录规则维护。
